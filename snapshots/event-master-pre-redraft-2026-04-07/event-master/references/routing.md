# Evidence Routing

When new docs, transcripts, Slack threads, or proposal bodies should update node knowledge, use:
- `/Users/nickita/.codex/skills/graph-evidence-routing/SKILL.md`

Core rule:
- route by what the evidence directly proves, not by what it vaguely relates to

Typical sequence:
1. find the artifact in the Events index or Granola export
2. search candidate nodes
3. pick one primary node
4. decide whether any secondary excerpt-only reuse is justified
5. update canonical raw storage and node addenda

Do not over-route full artifacts into many downstream nodes.
